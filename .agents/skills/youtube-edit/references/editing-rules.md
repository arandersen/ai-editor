## ⚙️ 2. Shared Core Standards Across ALL Video Formats (Universal Rules U1–U8)

These 8 foundational engineering & quality rules apply universally across **Couple Videos**, **Talking Head Videos**, and **Motion Graphics Animations**:

1. **Rule U1 — Zero-Latency Speech Start & 10ms RMS Acoustic Onset Synchronization**:
   - Start every video at `0:00:00` on the **exact first spoken syllable** (`0.04s` pre-consonant micro-padding, zero dead lead-in silence).
   - Never trust raw Whisper/ASR timestamps after pauses (which drift `0.4s–1.0s` early). Anchor every caption word and visual effect trigger (`tool-label`, `repo-card`, `top-callout`, `head-pop`, `stressed-word`) to the **verified 10ms RMS acoustic energy onset**.
2. **Rule U2 — Multimodal Visual Verification (`inspect_video.sh` + `view_file`)**:
   - Always run `./scripts/inspect_video.sh` and call `view_file` on both the generated contact sheet and the video file (`< 100 MB`) before cutting raw footage AND after rendering the final master to visually verify framing, eye-lines, card/UI artwork, and text placement.
3. **Rule U3 — Vibrant Native Emoji & Stroke Separation**:
   - When rendering overlays via macOS Swift (`AppKit`/`CoreText`), always separate stroked text runs (`Arial-Black` / `HelveticaNeue-Bold`) from `AppleColorEmoji` runs (shadow only, zero stroke) so negative stroke widths never strip or corrupt emoji colors. Never feed raw emojis into unpatched `libass` `.ass` strings where `Arial Black` renders `[?]` boxes.
4. **Rule U4 — Isolated Voice Loudness (`-14 LUFS`), `normalize=0` Mixing & 48kHz Resampling**:
   - Normalize the isolated dialogue stem to **`-14 LUFS`** (`true peak -1.5 dBTP`, `80 Hz` high-pass filter) **before** mixing with background music and SFX.
   - Always pass **`normalize=0`** to FFmpeg's `amix` filter (`amix=inputs=3:duration=first:normalize=0,alimiter=limit=0.95:level=0`) so SFX entrances never duck or pump the speaker's voice.
   - Ensure all SFX WAV files are resampled to **`48,000 Hz`** before sample-array or FFmpeg mixing so `44.1kHz` assets never play pitch-shifted.
5. **Rule U5 — Micro-Fades (`15ms–25ms`) on Every Audio Cut**:
   - Apply a `15ms–25ms` audio fade/crossfade (`afade` / `acrossfade`) + exact `apad`/`atrim` duration locking on every dialogue segment cut to eliminate zero-crossing clicks and cumulative A/V concat drift.
6. **Rule U6 — Native 4K Ultra HD Studio Master Export (`CRF 14` + `Rec.709`)**:
   - Never downscale 4K raw footage. Render final upload masters in **Native 4K (`2160×3840` for 9:16 vertical or `3840×2160` for 16:9 horizontal)** using `libx264` High Profile Level 5.2, `-preset slow -crf 14`, target bitrate `45–50 Mbps` (`-maxrate 65M -bufsize 90M`), explicit Rec.709 color tags (`-color_primaries bt709 -color_trc bt709 -colorspace bt709`), `-pix_fmt yuv420p`, and `320k` 48kHz AAC stereo audio.
7. **Rule U7 — Per-Project Folder Organization & Dedicated QC Subagent (`caption-qc-reviewer`)**:
   - Mirror `raw/<Project Name>/` across `renders/final/<Project Name>/`, `renders/drafts/<Project Name>/`, `transcripts/<Project Name>/`, and `broll/<Project Name>/`.
   - Run the dedicated QC verification check (`caption-qc-reviewer` subagent + contact sheet inspection) to ensure 100% of spoken words and visual triggers match the timeline.
8. **Rule U8 — Mandatory Self-Updating Rulebook Protocol (Never Skip)**:
   - Every time the user gives feedback on a video edit, **Gemini 4 Argon** must:
     1. Fix and re-render the current video.
     2. Update the relevant domain rulebook ([`editing-rules-couple.md`](./editing-rules-couple.md), [`editing-rules-talking-head.md`](./editing-rules-talking-head.md), or [`editing-rules-animation.md`](./editing-rules-animation.md)).
     3. Append a row to the **Master Feedback Changelog** below and report both the updated video path and the exact Rule # saved forever.
